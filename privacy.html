YouTube Crawler Drive Delivery

개인정보처리방침

시행일: 2026-09-20

이 문서는 운영자 개인의 일일 보고서 자동화 프로그램인 YouTube Crawler Drive Delivery가 Google 계정 및 Google Drive 정보를 처리하는 방법을 설명합니다.

1. 처리하는 정보와 목적

  • Google 계정 이메일: 승인 계정이 운영자가 지정한 계정인지 확인합니다.
  • OAuth 인증 정보: 사용자 동의에 따라 정기 실행 중 Google Drive API에 접근하고 접근 토큰을 갱신합니다. Google 비밀번호는 프로그램이 받거나 저장하지 않습니다.
  • Drive 폴더 및 파일 메타데이터: 지정 폴더 ID, 폴더 이름, 추가 권한, 보고서 파일 이름·ID·유형을 확인하여 업로드 대상과 동명 파일을 구분합니다.
  • 프로그램이 생성한 Excel 보고서: 공개 YouTube 영상 통계와 분석 결과를 담아 지정 Drive 폴더에 생성하거나 갱신합니다.

현재 Drive 인증 범위는 https://www.googleapis.com/auth/drive입니다. 이 범위는 계정 전체의 파일 읽기·쓰기 권한을 포함하지만, 프로그램은 지정 폴더의 보고서 및 자신이 만든 임시 테스트 파일에 필요한 작업만 수행합니다. 관련 없는 Drive 파일의 내용을 읽거나 다운로드하지 않습니다.

2. 저장 위치와 외부 서비스

OAuth 인증값은 운영자의 로컬 비밀 설정 파일 및 운영 Google Cloud 프로젝트의 Secret Manager에 보관합니다. 인증값은 공개 저장소나 보고서에 포함하지 않습니다. Google Cloud Run에서 자동 실행하며, BigQuery에는 공개 YouTube 데이터·분석 결과와 배치 상태·전달 성공 ID를 기록합니다.

생성된 보고서는 사용자가 지정한 Google Drive 폴더와 Telegram 대화에 전달됩니다. Drive에서 읽은 기존 파일의 내용이나 OAuth 인증값을 Telegram 또는 Gemini에 전달하지 않습니다. Gemini 분석은 별도로 수집한 공개 YouTube 영상 정보와 영상 입력을 대상으로 합니다.

이 안내 사이트는 GitHub Pages에서 제공됩니다. 페이지 자체에 광고, 분석 스크립트, 입력 양식 또는 쿠키를 추가하지 않습니다. 호스팅 제공자의 접속 정보 처리는 해당 제공자의 정책에 따릅니다.

3. 보관과 삭제

자동 실행을 위한 OAuth 갱신 토큰은 운영자가 연결을 유지하는 동안 보관하며, 연결 해제 시 로컬 비밀값과 Secret Manager의 관련 비밀 버전을 삭제할 수 있습니다. Google 계정에서 승인을 철회하면 해당 인증을 이용한 이후 접근이 차단됩니다.

Drive 보고서와 Telegram 메시지는 사용자가 삭제할 때까지 남을 수 있습니다. 연결 해제만으로 이미 전달된 보고서가 자동 삭제되지는 않습니다. Drive 테스트용 임시 파일은 연결 검사 후 삭제합니다. BigQuery의 데이터와 실행 이력은 별도의 자동 삭제 기간을 설정하지 않으며 운영자가 관리·삭제합니다.

4. 사용자의 선택과 승인 철회

Drive 저장 기능을 끄거나 Google 계정의 서드 파티 연결 관리에서 앱의 접근 권한을 철회할 수 있습니다. 이미 생성된 보고서는 Drive와 Telegram에서 직접 삭제할 수 있으며, 인증 정보와 운영 기록의 삭제 문의는 아래 이메일로 요청할 수 있습니다.

5. 이용 제한과 보호 조치

Google API에서 받은 사용자 데이터는 위에 설명한 보고서 전달과 운영 확인 목적으로만 사용합니다. 판매, 광고 타기팅 또는 일반화된 AI 모델 학습을 위해 사용하지 않습니다. Google API를 통해 받은 정보의 사용 및 다른 앱으로의 전송은 Limited Use 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

인증값은 소스코드와 분리하고, 운영 실행 계정에는 필요한 Secret 접근 권한을 부여합니다. Google 및 Telegram API 연결에는 HTTPS를 사용합니다. 운영자는 인증값을 외부에 공개하지 않고 접근 권한을 관리해야 합니다.

6. 변경 및 문의

처리 방식이 변경되면 이 문서와 시행일을 갱신합니다. 기존 동의 범위를 넘어서는 접근이 필요한 경우 새 승인을 요청합니다.
